# ObjectVerse

ObjectVerse 是一个基于 Spring Boot 的 Web 项目。

## 主要技术栈

- Java 17
- Spring Boot
- Spring MVC
- Thymeleaf
- MyBatis
- MySQL
- Maven

## 项目目录

```text
objectverse/
├── src/main/java/        # Java 源代码
├── src/main/resources/   # 配置、模板、静态资源及 Mapper 文件
├── src/test/             # 测试代码
├── docs/                 # 项目文档
├── sql/                  # SQL 脚本
├── uploads/              # 上传文件
└── pom.xml               # Maven 项目配置
```

## 启动项目

在 Windows 环境下，于项目根目录执行：

```cmd
mvnw.cmd spring-boot:run
```
